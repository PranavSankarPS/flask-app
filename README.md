# Flask CI/CD Pipeline Project

## Project Overview

A Dockerized Flask application integrated with GitHub Actions for Continuous Integration.

## Technologies

- Python
- Flask
- Docker
- GitHub Actions

## Features

- Containerized application
- Automated CI pipeline
- Dependency installation
- Build validation

## Project Architecture
Developer
   ↓
Git Push
   ↓
GitHub
   ↓
GitHub Actions
   ↓
Build & Validate
   ↓
Docker Image
